
# دو بیتی‌های عاشقانه

این پروژه یک وب‌اپلیکیشن ساده است که به شما اجازه می‌دهد پست‌های متنی و تصویری را منتشر کنید، و برای هر پست موزیک و ویدیو اضافه کنید. همچنین قابلیت لایک و کامنت برای پست‌ها نیز وجود دارد. این پروژه برای یک صفحه فیسبوک طراحی شده است که در آن با شعر و ویدیوهای کوتاه تولید محتوا می‌شود.

## ویژگی‌ها

### پست‌ها
- پست‌گذاری تنها برای ادمین از طریق پنل مدیریت
- پشتیبانی از موزیک، ویدیو و تصاویر برای هر پست
- امکان لایک و کامنت برای پست‌ها
- نمایش تاریخ به صورت شمسی
- پلیر شخصی‌سازی شده برای موزیک و ویدیو

### اکانت
- ثبت‌نام برای کاربران جدید
- تایید ایمیل برای امنیت بیشتر
- ورود به سیستم و دسترسی به پست‌ها

## ابزارها و کتابخانه‌ها
این پروژه از ابزارهای زیر استفاده می‌کند:

- `django`: فریم‌ورک اصلی برای توسعه وب
- `persiantools`: برای نمایش تاریخ شمسی
- `pillow`: برای پردازش تصاویر در پست‌ها
- `python-decouple`: برای مدیریت تنظیمات محیطی از فایل `.env`

## نصب و راه‌اندازی

برای نصب و راه‌اندازی پروژه به صورت محلی، مراحل زیر را دنبال کنید:

1. **کلون کردن پروژه**:
   ابتدا پروژه را کلون کنید:
   ```bash
   git clone https://github.com/Akbaroo/dobiti.git
   ```

2. **نصب وابستگی‌ها**:
   از `pip` برای نصب وابستگی‌ها استفاده کنید:
   ```bash
   pip install -r requirements.txt
   ```

3. **تنظیمات محیطی**:
   فایل `.env` خود را پیکربندی کنید. برای مثال، تنظیمات ایمیل به شکل زیر خواهد بود:
   ```ini
    EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
    EMAIL_HOST=smtp.gmail.com
    EMAIL_PORT=587
    EMAIL_USE_TLS=True
    EMAIL_HOST_USER=your_email@gmail.com
    EMAIL_HOST_PASSWORD=your_app_password
    DEFAULT_FROM_EMAIL=your_email@gmail.com
   ```

4. **اجرای پروژه**:
   برای راه‌اندازی پروژه محلی:
   ```bash
   python manage.py collectstatic
   python manage.py runserver
   ```

5. **اجرای مایگریشن‌ها**:
   اگر از پایگاه‌داده استفاده می‌کنید، ابتدا مایگریشن‌ها را اجرا کنید:
   ```bash
   python manage.py migrate
   ```
